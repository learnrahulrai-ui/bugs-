1. A program receives an input and changes stored state.
2. Stored state means the values and objects the program presently holds.
3. An invariant is a rule that a correct state change must preserve.
4. A system call can return zero to mean success.
5. A negative error number identifies a specific unsuccessful operation.
6. EIO is the named input/output error; -EIO is one negative return code.
7. The reported KVM path asserts that r equals either 0 or -EIO.
8. The execution instead reaches that assertion with a different value.
9. A value outside the accepted set causes a kernel warning.
10. The trace identifies the violated return contract, not yet the origin of the unexpected return.
11. The report shows a candidate violation of the rule derived above, not proof for every version.
