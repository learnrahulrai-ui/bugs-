1. A program receives an input and changes stored state.
2. Stored state means the values and objects the program presently holds.
3. An invariant is a rule that a correct state change must preserve.
4. A file has a content length measured in bytes.
5. An unbounded read requests data from its start through its current end.
6. The code first requests metadata to discover a finite end number.
7. Another writer can replace the file after that metadata request.
8. A read restricted to the earlier end number cannot retrieve bytes beyond that limit.
9. If old length is 52 and replacement length is 73, 73-52=21 new bytes are outside the requested range.
10. Returning 52 bytes is not the whole 73-byte replacement requested by the caller.
11. The report shows a candidate violation of the rule derived above, not proof for every version.
12. A local reproduction must record the exact source revision, input, output and control.
