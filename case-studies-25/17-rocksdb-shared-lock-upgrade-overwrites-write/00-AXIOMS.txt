1. A program receives an input and changes stored state.
2. Stored state means the values and objects the program presently holds.
3. An invariant is a rule that a correct state change must preserve.
4. A database key k begins with value v0.
5. A snapshot records the version of records visible at transaction start.
6. Another writer changes k to v_other after the snapshot.
7. A shared lock permits other readers; an exclusive lock excludes conflicting writers.
8. Upgrading a shared lock to exclusive requires validation of the snapshot.
9. The validation returns Busy for the conflicting newer write.
10. The reported failure overwrites Busy with OK from lock downgrade; commit then writes v_txn over v_other.
11. The report shows a candidate violation of the rule derived above, not proof for every version.
12. A local reproduction must record the exact source revision, input, output and control.
