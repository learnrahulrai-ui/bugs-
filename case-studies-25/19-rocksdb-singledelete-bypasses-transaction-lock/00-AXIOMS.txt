1. A program receives an input and changes stored state.
2. Stored state means the values and objects the program presently holds.
3. An invariant is a rule that a correct state change must preserve.
4. A key k has a saved value v.
5. An exclusive transaction lock on k should stop other writes to k.
6. A WriteBatch is a list of write commands passed to one Write call.
7. A batch lock collector examines each command and records keys to lock.
8. The collector handles Delete but does not handle SingleDelete in the reported revision.
9. The default SingleDelete handler returns OK for family zero without recording key k.
10. The write runs without the required lock and deletes k even while the other transaction holds it.
11. The report shows a candidate violation of the rule derived above, not proof for every version.
12. A local reproduction must record the exact source revision, input, output and control.
