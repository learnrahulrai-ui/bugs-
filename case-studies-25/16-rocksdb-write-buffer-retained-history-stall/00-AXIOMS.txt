1. A program receives an input and changes stored state.
2. Stored state means the values and objects the program presently holds.
3. An invariant is a rule that a correct state change must preserve.
4. A memory budget is the maximum charged memory allowed for writes.
5. The report sets a 160 MiB budget and a 64 MiB write buffer.
6. A write buffer holds new records before they move to a persistent table.
7. TransactionDB retains some old flushed buffers as history.
8. The manager still counts retained history as charged memory.
9. At 160.3 MiB used, writes stop; a 32 MiB mutable buffer is below half of the 160 MiB budget.
10. If no flush or history release occurs, waiting for memory cannot by itself free memory.
11. The report shows a candidate violation of the rule derived above, not proof for every version.
12. A local reproduction must record the exact source revision, input, output and control.
