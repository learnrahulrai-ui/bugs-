1. A program receives an input and changes stored state.
2. Stored state means the values and objects the program presently holds.
3. An invariant is a rule that a correct state change must preserve.
4. A buffer has a fixed 1000-byte capacity.
5. snprintf accepts a destination and a maximum length.
6. When output is too long, snprintf returns the number of bytes it would have written.
7. That returned count can be greater than the bytes actually stored.
8. Adding the larger count to a cursor can move the cursor beyond the 1000-byte buffer.
9. Subtracting a too-large cursor from 1000 as unsigned arithmetic creates a huge positive size.
10. A later formatted write then receives an address beyond the buffer and an invalid size.
11. The report shows a candidate violation of the rule derived above, not proof for every version.
12. A local reproduction must record the exact source revision, input, output and control.
