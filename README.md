Real open-source bug study archive.

Each numbered directory is one bug. Start with 00-AXIOMS.txt, then 01-EXECUTION.txt, then 02-REPRODUCE.txt, then 03-EVIDENCE.txt. All observations must be independently verified. No fix is included.

Status words: REPORTED = observed by upstream reporter; REPRODUCED_HERE = executed in this workspace; UNTESTED_HERE = not executed in this workspace.

Open-source projects and issue authors retain their respective rights. Source links point to original reports and code. This repository contains original study notes, not a replacement for upstream source.
